# ЛР1: обработка и очистка данных на Python

Публичная обезличенная версия учебного проекта. ФИО, группа, отчёт Word,
пароли, исходные CSV и локальная история коммитов не опубликованы.

## Результат
Обработана предоставленная локальная выборка INBO: 1 600 000 GPS-наблюдений,
33 исходных поля. После очистки: 1 600 000 строк и 39 полей.
Профиль и ограничения: DATASET.md. Реальные замеры: docs/measurements.
Блокноты 01_overview и 02_cleaning выполнены локально; пути окружения обезличены.
03_colab предназначен для запуска в Google Colab.

## Запуск
Нужен Python 3.12.14. Создайте .venv, установите зависимости через
`pip install -r requirements.txt` либо `poetry install`.
Поместите предоставленные CSV в data/raw:
- inbo_gull_gps_tracking_1gb.csv
- radar_track.csv
- radar_site.csv
- radar_species.csv

Из корня проекта: `python -m src.pipeline`.
Отладка: `python -m src.pipeline --mode debug --output data/processed/debug.parquet`.
Полное пересоздание: `python -m src.rebuild`; для этой команды требуется PostgreSQL.
Скопируйте .env.example в .env и заполните реквизиты своей учебной базы.
Никогда не публикуйте .env.

SQLite и PostgreSQL создаются кодом в src/database.py; определения таблиц
и контрольные запросы находятся в sql/. Источники и лицензия описаны в DATASET.md.
Измерения относятся к одному компьютеру, а не являются универсальным рейтингом.
Набор более 1 ГБ сам по себе не доказывает принадлежность к Big Data.
