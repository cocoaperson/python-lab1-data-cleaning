# ЛР1: обработка и очистка данных на Python

Публичная обезличенная версия учебного проекта. ФИО, группа, отчёт Word,
пароли, исходные CSV и локальная история коммитов не опубликованы.

## Результат
Обработана предоставленная локальная выборка INBO: 1 600 000 GPS-наблюдений,
33 исходных поля. После очистки: 1 600 000 строк и 39 полей.
Профиль и ограничения: DATASET.md. Реальные замеры: docs/measurements.
Блокноты 01_overview и 02_cleaning выполнены локально; пути окружения обезличены.
03_colab_executed.ipynb содержит пять выполненных в Google Colab кодовых ячеек.
Облачная версия Python 3.13.16 отличается от локальной 3.12.14.

## Запуск
Нужен Python 3.12.14. Создайте .venv, установите зависимости через
`pip install -r requirements.txt` либо `poetry install`.
Поместите предоставленные CSV в data/raw:
- inbo_gull_gps_tracking_1gb.csv
- radar_track.csv
- radar_site.csv
- radar_species.csv

Из корня проекта: `python -m src.pipeline`.
Отладка: `python -m src.pipeline --mode debug --output data/processed/debug.parquet`.
Полное пересоздание: `python -m src.rebuild`; для этой команды требуется PostgreSQL.
Скопируйте .env.example в .env и заполните реквизиты своей учебной базы.
Никогда не публикуйте .env.

SQLite и PostgreSQL создаются кодом в src/database.py; определения таблиц
и контрольные запросы находятся в sql/. Источники и лицензия описаны в DATASET.md.
Измерения относятся к одному компьютеру, а не являются универсальным рейтингом.
Набор более 1 ГБ сам по себе не доказывает принадлежность к Big Data.


## Проверка через приложения
В DBeaver создана SQLite dataset_gui.db через редакторы столбцов, PK/FK и индексов.
В PostgreSQL gui_lab скопированы определения таблиц через конструктор;
четыре внешних ключа добавлены через диалоги. В обе базы загружены 1 600 000 наблюдений,
контрольные количества и средние совпали. Аудиты — docs/measurements/dbeaver_*_audit.json.
GUI SQLite не содержит CHECK координат/неопределённости и индекса deployment_pk,
имеющихся в исходной базе. Замеры относятся к исходным базам до добавления gui_lab.

sql/schema_sqlite.sql и sql/schema_postgres.sql получены через Generate SQL → DDL.
Дополнительные определения GUI-баз — schema_sqlite_gui.sql и schema_postgres_gui.sql.
Экспорт PostgreSQL относится к gui_lab: сначала создайте схему gui_lab.
Полный src.database заново формирует собственные DDL при пересоздании.
ER-диаграмма экспортирована из DBeaver: docs/er_dbeaver.png.
В VS Code проверены Python 3.12.14, выбор ядра и остановка F5 на breakpoint.
Для отладки применяется встроенная консоль, без зависимости от профиля PowerShell.
