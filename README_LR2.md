# ЛР2 — разведочный анализ GPS-наблюдений

Продолжение ЛР1 на том же `data/processed/clean.parquet`. Исходные строки и поля не меняются.

## Файлы и связь с ЛР1

- `notebooks/03_eda.ipynb` — выполненный блокнот с шестью встроенными графиками.
- `src/eda.py` — функции расчётов и построения графиков.
- `tests/test_eda.py` — проверки календаря, пропусков, редких групп и границ правил.
- `data/processed/clean.parquet` — локальная копия результата ЛР1, не публикуется.
- `plots/` — шесть PNG, создаются при выполнении блокнота, не публикуются.
- `results/` — полные таблицы CSV, сведения о расчётах и замер JSON; не публикуются.
- `logs/eda.log` — количество аномалий, пересечение, сравнение с ЛР1 и SHA-256.
- `docs/lr1_review.md` — результаты проверки ЛР1 и обоснование продолжения.
- `docs/lr3_handoff.md` — выбранные признаки и наблюдения для следующей работы.

ЛР2 опубликована в ветке `lab2-eda` существующего учебного репозитория.
Ветка основана на публичной обезличенной истории ЛР1; основная ветка ЛР1 не меняется.
Локальная папка ЛР1 хранится отдельно и не используется как рабочая папка ЛР2.

## Воспроизведение

Нужен Python 3.12.14 и зависимости из `poetry.lock` / `requirements.txt` ЛР1.
Для новой установки: создать `.venv`, затем `python -m pip install -r requirements.txt`
или `poetry install`. Не требуется повторно обрабатывать исходный CSV или запускать БД.

Поместить результат ЛР1 в `data/processed/clean.parquet`.
Ожидаемый SHA-256:
`05eb88e9217b146a80734a791eff8b7c88100cce5c7ffb0b1f25fdf6564ee9b3`.

В PowerShell из папки ЛР2:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m ruff check src/eda.py tests/test_eda.py
.\.venv\Scripts\python.exe -m jupyterlab notebooks/03_eda.ipynb
```

В Jupyter выбрать ядро Python проекта, затем **Restart Kernel → Run All**.
В VS Code открыть папку ЛР2 и выбрать интерпретатор `.venv\Scripts\python.exe`.
Вычислительная логика импортируется из `src/eda.py`; блокнот допустимо запускать
как из корня проекта, так и из каталога `notebooks`.

Сохранённое выполнение: 14 кодовых ячеек, шесть рисунков, ошибок нет.
Изменение времени при повторном выполнении нормально: сравниваются медианы трёх
повторов на конкретной машине после одного прогрева. Параметры и версии сохранены
в выводе блокнота и `results/benchmark.json`.

## Методика

Цель: `minimum_distance_above_surface_in_meters` (м). Дата: `event_date` (UTC).
Группа: `scientific_name`. Период агрегации — календарный месяц.
Пустые месяцы имеют нулевой объём, но неопределённые медиану и среднее.
Редкие группы — менее 1% строк; объединяются только на графиках.

Правила аномалий заданы до рисунков: строго вне 1,5 IQR и строго меньше 0 м.
Пропуски не отмечаются. Маски имеют длину исходного набора. Флаги совпадают с ЛР1;
строки сохраняются. Автоматическое признание отрицательной высоты ошибкой не делается.

Использованы все 1 600 000 записей, без подвыборки; пропусков высоты — 11.
Расчёт средней в цикле и NumPy использует один и тот же массив из 1 599 989 чисел.
39 месяцев, два вида, 145 особей. Проверки гипотез, доверительные интервалы,
корреляции и логарифмическое масштабирование отложены до ЛР3.

Источники: методические указания ЛР2, результат очистки ЛР1 и паспорт `DATASET.md`.
Данные INBO; происхождение и ограничения подробно описаны в паспорте ЛР1.
