# Проверка ЛР2 по методическим указаниям

Работа продолжает тему GPS-наблюдений чаек INBO и использует полный результат очистки ЛР1.

| Шаг | Выполнение и свидетельство |
|---|---|
| 1. Проект ЛР1 | Тот же репозиторий, ветка lab2-eda. clean.parquet совпадает с ЛР1 по SHA-256; все четыре raw-файла совпадают с исходным манифестом. Локальные папки разделены по заданию пользователя, окружение восстановлено с теми же версиями. |
| 2. Признаки | minimum_distance_above_surface_in_meters, event_date, scientific_name; основания выбора приведены в начале блокнота. Шаг — календарный месяц. |
| 3. Сводка | Таблица 1: размер, пропуски, минимум, Q1, медиана, среднее, Q3, максимум и правосторонняя асимметрия. |
| 4. Время | Полный календарь из 39 месяцев; пустому периоду соответствует нулевой объём и NaN для статистик. Полный ряд в блокноте, выбранные периоды в отчёте. Тест покрывает отсутствующий месяц. |
| 5. Группы и pivot | Размер, медиана, среднее и доля пропусков по двум видам. Порог редкости строго <1%; объединено 0 категорий. В таблице все категории сохранены. Pivot вида на месяц содержит медианы, NaN не заменяется нулём. |
| 6. Аномалии | Правила заданы до рисунка: 1,5 IQR и высота <0. Маски длины N возвращаются вместе с количествами. График использует готовые маски, что проверено отдельным тестом. Таблица 4 имеет строку пересечения; журнал фиксирует оба количества и пересечение. Строки не удаляются. |
| 7. Векторизация | Одно среднее на одном float64-массиве из 1 599 989 значений. Равенство проверено до замера. Один прогрев, три повтора, медианы времени. В таблице 5 отдельно указаны отношение и число значений. |
| 8. Рисунки | Ровно шесть обязательных типов. Названия, единицы осей, PNG и следующие Markdown-ячейки с численными наблюдениями. data/ и plots/ исключены из Git. |
| 9. Проверка и сдача | Выполнены все 14 ячеек с чистого ядра, ошибок нет. Четыре теста и Ruff проходят. Код и выполненный блокнот сохранены в Git. |

Машинные результаты проверки: [lr2_validation.json](lr2_validation.json).
Полный Word-отчёт хранится локально: оформление, титульный лист и стили взяты из ЛР1,
включены паспорт, шесть обязательных таблиц, шесть графиков, версии замера,
ссылка на блокнот, ход выполнения, ограничения и вывод для ЛР3.

В ЛР2 не выполняются тесты гипотез, корреляции, доверительные интервалы, бутстреп,
поправки множественных сравнений или логарифмическое масштабирование.
Высота анализируется как записанное GPS-значение; отрицательные измерения не объявляются
безусловными ошибками всех координат. Повторные наблюдения 145 птиц не считаются независимыми особями.
